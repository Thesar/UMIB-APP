# Screamulus

Screamulus is an educational mathematics mobile application developed using React Native, Expo, and TypeScript.

## Project Idea

Screamulus aims to make mathematics interactive, creative, and entertaining by using smartphone hardware.

Future features will include:

- Creating mathematical functions using microphone input and phone movement.
- Understanding trigonometry, derivatives, and integrals through interactive challenges.
- Photographing hand-drawn curves and approximating their equations.
- Replaying mathematical performances with synchronized audio.
- Saving mathematical creations in a gallery.

## Current Version

The first version contains a list of mathematical lessons, reusable cards, and detailed explanations.

## Technologies

- React Native
- Expo
- TypeScript
- Expo Router
